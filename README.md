# spotify

WorkVibes
WorkVibes is a Spotify-powered web application that recommends music based on a user's profession. Users will select a profession, and the application will suggest music genres and Spotify content that match the typical energy, focus, or atmosphere of that type of work.
Project Overview
The goal of WorkVibes is to make music discovery simple and fun by connecting a person's profession with music that fits their work environment.
Planned Features
- Select a profession from a list
- Match each profession with recommended music genres
- Retrieve music data from the Spotify Web API
- Display recommended songs, artists, or albums
- Provide links to open recommendations in Spotify
- Use a frontend and backend structure
- Store API credentials securely using environment variables
Prerequisites
Before running this project, make sure you have the following installed:
- Node.js 16 or later
- npm 8 or later
- Git
- A modern web browser such as Chrome, Firefox, Safari, or Edge
- A Spotify Developer account
- Spotify API credentials
